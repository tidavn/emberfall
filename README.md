Emberfall — Ashes of the Last Lantern: a top-down arena survival game. You are the last lantern-keeper; hold the arena through 10 waves of shadow wisps, pick blessings between waves, and face the Ashen Maw. Move with WASD or arrows, aim with the mouse, hold click or Space to shoot embers. Pure static files, no build step, no network — all art is drawn in code and all sound is synthesised with the Web Audio API.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static file server and open `index.html`.
